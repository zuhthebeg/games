# 감자특공대 v3 — PixiJS 렌더러 교체 + 무기 비주얼 브리프

전제: v2(전투감·무기14·캐릭터10·성장) 머지 후 착수. v1/v2 브리프 유효, 충돌 시 이 문서 우선.
목표 한 줄: **"무기에서 정확히 나가는 게 보이고, 무기마다 나가는 게 다르다."**

## 0. 기술 결정 (Opus, 변경 금지)
- **PixiJS v8 (WebGL, WebGPU 자동, Canvas 폴백)** 로 `render.js` 교체. 2D 탑다운 스프라이트 게임에 필요한 건 배칭·블렌드모드·필터(블룸/글로우)·파티클 성능이고, 이게 Canvas2D 대비 체급 차이를 만든다.
- **three.js 안 씀**: 3D 카메라·조명이 줄 이득이 없고 번들·복잡도만 늘어난다.
- **물리엔진(Matter/Rapier) 안 씀**: 호스트 권위 시뮬이 스냅샷으로 동기화되는 구조라 외부 물리 상태를 들이면 동기화가 깨진다. 넉백·분리력은 기존 sim 코드로 충분.
- **시뮬(sim.js)·넷코드(net.js)는 건드리지 않는다.** 렌더는 world/snapshot + fx 이벤트만 읽는 순수 뷰. (필요한 좌표가 없으면 sim이 아니라 fx 페이로드 추가로 해결 — 이때만 net 인코더 수정 허용, 테스트 동반)
- **CDN 핫링크 금지**: `pixi.min.mjs`(v8 최신 안정판)와 `pixi-filters`(AdvancedBloom/Glow만 쓰면 해당 번들)를 `spudsquad/vendor/`에 셀프호스팅. `npm pack`으로 받아 파일 복사, 버전은 `vendor/VERSIONS.md`에 기록.
- 참고 스킬(반드시 읽어라): `/home/cocy/.openclaw/workspace/.agents/skills/pixijs/SKILL.md`(라우터) → `pixijs-scene-particle-container`, `pixijs-filters`, `pixijs-blend-modes`, `pixijs-performance`, `pixijs-scene-mesh`, `pixijs-assets`, `pixijs-ticker`. 타격감은 `.agents/skills/game-feel/SKILL.md` + `references/feedback-recipes.md`(트라우마 셰이크, 이징 표, 중요도 티어, 접근성 토글).

## 1. 레이어 구조 (Container 순서)
1. `ground`: 배경 TilingSprite + 데칼(외계 점액 얼룩·그을음, 3초 페이드, 최대 120개 풀)
2. `shadows`: 모든 유닛 아래 타원 그림자(단일 텍스처, 알파 0.25)
3. `pickups`: 재료(초록 크리스탈 — 둥둥 뜨는 사인 + 반짝), 상자
4. `units`: 적·플레이어(y 정렬), 무기 스프라이트
5. `projectiles`: 일반 블렌드 투사체(돌·볼트·로켓 몸체)
6. `fxAdd`: **ADD 블렌드** — 총구섬광, 트레이서, 빔, 번개, 화염, 폭발 불꽃, 스파크. **블룸 필터는 이 레이어에만** (전체 화면 필터 금지 — 모바일 성능)
7. `ui world`: 데미지 숫자(BitmapText), HP바
8. 화면 공간: 비네트(가장자리 어둡게), 피격 붉은 테두리 플래시

## 2. 무기별 비주얼 스펙 (핵심)
공통: 발사 원점은 v2에서 sim이 export한 무기 끝 좌표(`muzzle`) — 렌더도 같은 함수로 무기를 그 자리에 그린다. **투사체가 무기 끝이 아닌 곳에서 나오면 실패.**
- 무기 스프라이트: 조준 방향으로 회전(좌향이면 y 반전), 발사 시 **반동**(조준 반대 6px, easeOutBack 0.12s 복귀), 발사 직후 0.05s 살짝 커짐.
- **총구 섬광**: 무기 끝에 별 모양 ADD 스프라이트 2프레임(크기 무기별), 랜덤 회전.
- **탄피**(gun 클래스): 무기 옆으로 작은 황동 사각 파티클 튀어나와 회전하며 0.4s 낙하·페이드.

| 무기 | 투사체/효과 |
|---|---|
| pistol | 노란 캡슐 트레이서(길이 18, 두께 4) + ADD 글로우, 뒤로 잔상 3개 |
| smg | 주황 짧은 트레이서(길이 12, 두께 3), 연사라 섬광 작게, 탄피 많이 |
| shotgun | 펠릿 4발(작은 흰 점+짧은 꼬리) + 발사 순간 부채꼴 연기/불꽃 원뿔(0.1s) + 흔들림 1px |
| slingshot | 회색 돌 스프라이트 회전 + 바닥 그림자(높이 포물선 연출), 튕길 때 먼지 퍼프 |
| crossbow | 볼트 스프라이트(진행방향 정렬) + 얇은 흰 궤적, 관통 시 적 뒤로 튀는 파편 |
| rocket | 로켓 몸체 + **연기 꼬리 파티클**(회색, 커지며 페이드) + 불꽃 노즐. 폭발 = 섬광 원(ADD, 0.08s) → 충격파 링(반경까지 확장, 두께 감소) → 불꽃 파티클 20 + 연기 10 + 그을음 데칼 + 트라우마 0.4 |
| laser | **빔**: 무기 끝→사거리 끝(또는 관통 끝)까지 3겹(흰 코어 3px / 시안 8px / 외곽 글로우 18px ADD), 폭 테이퍼, 0.12s 동안 두께 수축 + 미세 떨림. 관통한 모든 적 위치에 스파크 버스트 |
| staff | **번개**: 무기 끝→1번 적→2번…연쇄를 지그재그 폴리라인(세그먼트 8~12, 2프레임마다 재생성)으로, 흰 코어+노랑 글로우, 가지 1~2개. 연쇄 지점마다 작은 섬광 |

| hammer | 내려찍기: 치켜들기(0.2s anticipation, 살짝 뒤로 기울임) → 쾅: 원형 충격파 링 + 흙먼지 파티클 12 + 금 간 바닥 데칼 + 트라우마 0.25 |

## 3. 타격감 정리 (v2 기능을 Pixi로 격상)
- 흰 플래시: 적 스프라이트 `tint`만으로는 흰색이 안 나옴 → ColorMatrixFilter 공유 인스턴스를 명중 중인 적에게만 0.08s 부착하거나, 흰 실루엣 텍스처 한 장을 겹쳐 알파 페이드(권장 — 필터 남발 금지).
- 스쿼시&스트레치: easeOutBack/elastic (game-feel 이징 표 따름). 선형 트윈 금지.
- 화면 흔들림: **트라우마 모델**(trauma², 매 프레임 감쇠, 노이즈 샘플), 카메라 컨테이너 오프셋에만 적용. 설정에서 끄기.
- 히트스톱: v2 규칙 유지(로컬 렌더만).
- 사망: 흰 팝 → 조각 파티클(적 색) + 점액 데칼.

## 4. 성능 예산 (측정 필수)
- 파티클 전부 **풀링**, ParticleContainer 사용, 동시 상한 1500(초과 시 가장 오래된 것 재사용).
- 텍스처는 스프라이트시트 한 장으로 합쳐 배칭(에셋 webp들을 런타임에 로드 후 `Assets` 번들; 가능하면 빌드 스크립트로 아틀라스 생성해 커밋).
- 목표: 적 220 + 파티클 1000에서 **데스크톱 60fps, 모바일 저사양(CPU 4x 스로틀) 45fps 이상**. 헤드리스 크로미움 CDP `Emulation.setCPUThrottlingRate(4)`로 측정해 `spudsquad/PERF.md`에 기록.
- `devicePixelRatio`는 min(2, dpr). 저사양 감지(평균 프레임 > 24ms 3초 지속) 시 블룸 off → 파티클 절반 자동 강등.
