## Evidence and fixes

1. **Per-sprite hit filter stalls rendering.** Canvas `brightness(0) invert(1)` forces costly filtered rasterization in this Chromium software-rendered environment. A runtime intervention disabling *only* that filter changed frame-interval p95 from899.9 to116.7ms; disabling only shadows did not materially fix it (833.3ms). Replace it with a white source-in alpha mask built once per enemy/character asset; no background/weapon-mask allocation and no per-frame filter. Appearance remains a white hit flash.
2. **Hitstop freezes the whole world while movement continues.** Renderer returned before painting during40ms hit feedback, producing47 skipped paints in the fixed replay. Keep camera/world paints running; enemy hit squash, flash, particles, shake and boss slow effects remain. No timestep/catch-up changes.
3. **Unchanged HUD rebuilds DOM.** Twenty identical updates performed140 redundant text/team writes. Changed-only text/width setters and a cached team markup string eliminate these writes while preserving actual health/money/team updates.
4. **Auto Ads is loaded by this page's GTM.** A passive live request/DOM audit saw the AdSense SDK, show_ads_impl, DoubleClick ad requests and an auto-placed in-page slot. Anchor/vignette was not observed in that single audit. Remove this page's GTM head loader and noscript iframe instead of hiding ads or manipulating provider frames. This game has **zero ads in every state**, including lobby/shop/results. Central GTM and other pages are untouched. This also removes this page's GTM-provided GA4 tracking; there is no analytics-only bypass. Any reserved single lobby/result banner is a separate future decision, not included here.
5. DOM regression exposed a landscape52px override; keep the requested56px reserved header clearance in all orientations, plus safe-area inset.

## Packet budget limitation

The old '<8KB' unit test uses220 blob enemies with empty FX; it is not a runtime cap. New characterization tests cover150 enemies/four players/50 hits (6006bytes, below8KiB), and150 hits (8856bytes, retaining all rows, above8KiB). The relay source `realtime-poc/src/room-do.ts:handleRt` rejects `payload.length >32768` **string characters**, not8192bytes. Fixed replay max9451bytes and other rapid-combat runs reached~20KiB. **Hard8KiB enforcement is not implemented or claimed.** No evidence showed this as the cause of relay packet loss; neither server nor transport was changed.
