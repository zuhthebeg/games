# 감자특공대 구현 메모

## 단순 해석
- 무기 판매는 현재 웨이브 가격 × 티어의 50%를 내림한다. 티어 무기 판매/구매 가격에 같은 배율을 쓴다.
- 보스는 웨이브 시작 시 등장한다. 게임오버 보상은 완료한 웨이브 수(패배 시 현재 웨이브 제외)로 계산한다.
- 상점 오퍼의 난수는 플레이어별로 독립적이다. 잠근 칸은 다음 상점까지 보존한다.
- 웨이브 시작 시 HP는 새 로드아웃의 최대 HP로 초기화된다. 죽은 플레이어는 웨이브 종료 직후에는 50% HP로 부활한다.

## 질문
1. 웨이브 종료 자동흡수 재료는 팀원에게 어떻게 배분해야 하나? 현재는 생존자 중 첫 번째에게 지급한다.
2. 웨이브 종료 부활 HP 50%와 다음 웨이브 시작 HP 초기화(로드아웃 payload에 HP 필드 없음) 중 어떤 규칙을 최종 적용할까? 현재 다음 웨이브는 최대 HP로 시작한다.

## 알려진 한계
- ko/en/zh-TW 전환은 메뉴·핵심 UI 문구에 적용되며 아이템·무기·캐릭터의 이름과 설명은 한국어 데이터가 표시된다.
- 실제 워커는 전송·resync·재시작까지 확인했지만, 원격 2대의 브라우저에서 20웨이브 전체 플레이를 수동 검수하지 않았다.
- 모바일 세로 상점은 CSS 축소·스크롤 폴백이 있지만 모든 기기에서 무스크롤 한 화면을 실측하지 않았다.
