발열 비교는 쉬지 않고 B → A → B 실행. 마지막 B의 p95 상승은 드리프트 단서일 뿐 온도 측정이 아니다. 120Hz 기기는 60fps 이상이어도 정상. rAF 간격은 GPU 완료 시간이 아니다. 엔진 선택은 실제 중저가 안드로이드 결과로만 한다.

초기화 시간은 모듈 import + 아틀라스 생성 + 렌더러 생성 + 첫 렌더 포함. 반복 A는 Pixi 모듈 캐시 사용: 첫 A만 콜드 로드 근사. JS heap은 탭 전체의 비표준 관측값이며 Canvas/GPU 메모리를 포함하지 않는다. RGBA 바이트는 생성된 backing store 하한 추정(드라이버·프레임버퍼 제외).
